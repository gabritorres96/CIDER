# Licences and third-party material

CIDER itself: **MIT** (see `LICENSE`). Chosen as a permissive default; change it deliberately if
the project later integrates copyleft components.

## Build/runtime dependencies

| Component | Used for | Licence | How it is used |
| --- | --- | --- | --- |
| C++ standard library / MSVC runtime | everything | Microsoft redistributable terms | linked normally |
| CMake, Visual Studio | build | their own | tools only |
| **7-Zip** (optional) | `.dmg` extraction | GNU LGPL, with BSD-3-Clause parts and an *unRAR licence restriction* (see <https://www.7-zip.org/license.txt>) | **not bundled, not linked, not redistributed**: CIDER runs an installed `7z.exe` as a separate process. If a future release ships 7-Zip, its licence text must ship with it |

No third-party code is vendored in the repository. Development-only material that is **not** committed
(`.toolchain/`, `.validation/`, git-ignored):

* portable **LLVM 23.1.3** (Apache-2.0 WITH LLVM-exception) used to build real Mach-O fixtures, ASan and fuzzers;
  **libFuzzer sources** (same licence) are compiled locally from `llvm-project/compiler-rt/lib/fuzzer`;
* three **third-party release DMGs** (Rectangle, Stats, MonitorControl; each project's own licence, believed to be
  MIT — verify before redistributing) downloaded for validation only; never committed or redistributed.

The committed real fixtures (`tests/fixtures/real`) are compiled from sources written for this project plus a
hand-written libSystem `.tbd` stub; they contain no Apple code.

## Reference material (not copied)

* Mach-O, FAT, UDIF (`koly`/`mish`), ISO 9660/ECMA-119, Joliet and the code-signature blob layouts
  were implemented from public format descriptions. **No Apple source or header is included.**
  Constants and field layouts are facts of the formats; this is not legal advice.
* Wine (LGPL), Darling (GPL-3.0), GNUstep (libobjc2: MIT; gnustep-base: LGPL-2.1+): **no code
  copied**. Before integrating any of them (planned: libobjc2 evaluation in 0.4) verify: licence
  and distribution obligations, Windows/Clang compatibility, ABI compatibility with Apple's
  Objective-C runtime, and technical limitations.
* No Apple frameworks, system libraries or DMGs are downloaded or distributed. Test images are
  generated by the test code.
